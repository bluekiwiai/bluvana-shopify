# Bluvana silk Shopify theme

Local source for Bluvana's silk product-line storefront theme.

## Safe development workflow

Run commands from this directory.

```sh
# Start a disposable development theme with live preview and hot reload
shopify theme dev --environment bluvana

# Check Liquid and theme files before uploading
shopify theme check
```

Use a development or unpublished theme for review. Do not push or publish a live theme unless that exact live action is explicitly intended.
