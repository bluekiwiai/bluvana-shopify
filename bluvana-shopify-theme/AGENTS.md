# Main Bluvana theme

- This directory contains the main Bluvana Shopify Online Store 2.0 theme.
- The remote live theme is `Horizon` with ID `141773373502`.
- Use the `bluvana` environment in `shopify.theme.toml` for store-connected commands.
- Run `shopify theme check` after edits.
- Preview with `shopify theme dev --environment bluvana` or an unpublished theme.
- Never push to or publish the live theme unless the user explicitly requests that exact live action.
- Before pulling remote theme files, inspect Git status and local diffs.
